# 最爱的霜霜｜静态回忆网页

这是一个可部署到 GitHub Pages 的静态网页模板。当前照片、故事文字和音乐均为占位内容，替换后再发布。

## 文件替换
- 将照片放入 `assets/`，命名为 `photo-01.jpg`、`photo-02.jpg`、`photo-03.jpg`（可继续增加照片区块）。
- 将你有权使用、适合分享的音乐文件放入 `assets/`，命名为 `music.mp3`。网页不会自动播放，需要访客点击播放。
- 用文本编辑器打开 `index.html`，把示例故事、信件和结尾改成你自己的话。

## 发布到 GitHub Pages
1. 在 GitHub 新建一个仓库，例如 `shuangshuang-memory`。
2. 上传 `index.html` 和整个 `assets` 文件夹（保持目录结构）。
3. 进入仓库 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub Pages 部署完成，复制显示的网页地址即可放进邮件。

## 隐私提醒
GitHub Pages 是公开网页托管。不要放身份证件、住址、联系方式、私密聊天记录等敏感内容；知道链接的人也可能转发或访问。若照片涉及对方隐私，发布前请慎重考虑。仓库设为 private 不代表 Pages 页面本身是私密访问。
